# ⏰ Wake Up

### Wake up on time. Build better routines.

**Wake Up** is an Android alarm app in active development, designed to make waking up easier through personalized schedules, recurring alarms, and interactive wake-up challenges.

The goal is to build a practical, reliable application that helps people manage their mornings without the hassle of manually configuring multiple alarms.

> 🚧 **Status: Actively in Development**
>
> Wake Up is an evolving product. Core functionality, scheduling behaviour, and the overall user experience are being developed and tested.

---

## 🌅 About the Project

Waking up on time shouldn't require manually setting and managing a different collection of alarms every day.

Wake Up aims to simplify this experience by letting users configure their waking routines and manage them from one place.

Whether it's waking up for college, getting ready for work, or maintaining a consistent morning routine, Wake Up is being built to make alarm management more flexible and convenient.

This project focuses on developing a functional Android application, with an emphasis on real scheduling behaviour, usability, and a consistent user experience.

## ✨ Key Features

The following capabilities define the product's development roadmap:

- ⏰ **Custom Alarms** — Create, edit, enable, and disable alarms.
- 📅 **Flexible Scheduling** — Configure alarms for specific days of the week.
- 🔁 **Recurring Alarm Sequences** — Schedule multiple alarms at configurable intervals.
- 🧠 **Smart Sequence Management** — Cancel remaining alarms for the current morning when the user completes the wake-up sequence, while preserving future scheduled occurrences.
- 🧩 **Wake-Up Challenges** — Explore interactive dismissal methods designed to encourage users to get out of bed.
- 💬 **Routine-Based Setup** — Work toward simpler routine creation through natural-language input.
- 🎨 **Minimal User Experience** — A calm, refined interface with soft depth, subtle shadows, and carefully considered details.
- 📱 **Android-Focused Development** — Build and validate the application for real Android devices.

*These features describe the intended product direction. Their implementation and testing status may vary during development.*

## 🎯 Product Vision

Wake Up is being developed around three principles:

**Simplicity** — Make setting up a waking routine easier than manually managing multiple alarms.

**Flexibility** — Support different schedules for weekdays, weekends, college, work, and personal routines.

**Reliability** — Treat alarm scheduling as core functionality, not merely a visual interaction. Correct behaviour, permission handling, and device compatibility are important parts of the development process.

The long-term vision is to create a useful everyday product that helps people establish more consistent waking habits.

## 🎨 Design Philosophy

Wake Up follows a clean, minimal, and tactile design direction.

Its visual identity emphasizes:

- 🤍 Soft neutral surfaces and restrained accent colours.
- 🫧 Subtle shadows and a gentle three-dimensional appearance.
- ✍️ Clear typography and readable alarm times.
- 🧘 Calm layouts without unnecessary visual clutter.
- 👆 Simple, intuitive interactions.

The interface is designed to support the product's functionality rather than serve as a standalone visual showcase.
